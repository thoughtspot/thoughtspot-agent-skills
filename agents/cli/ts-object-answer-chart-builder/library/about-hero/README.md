# About this Liveboard

The opening tile: the Liveboard's purpose, three computed stakes, who it is for and the terms it uses.

| | |
|---|---|
| Model | (Sample) Retail - Apparel |
| Search | `[sales] [quantity purchased] [date].monthly` |
| Library | HTML (no chart library) |
| Tile | 12x8 grid units (01 About tab) |
| Data mode | B, live only. With no rows it shows an empty state that names the search. |
| CDN | none (Geist font link only) |

## Interactions
Click a person or a term to expand it.

## Notes
Generated by `ts-object-liveboard-chart-builder/scripts/build-narratives.mjs` from its `narratives/render.js` and `liveboards/amuzing-chart-samples/narratives/about-hero.cfg.js`. Every sentence and number is computed from the rows the search returns, and each degrades to a plain message when a filter leaves too little data. The prompts are static text.

## Paste
chart.html into the HTML tab, chart.css into the CSS tab, chart.js into the JS tab, then bind the search above.
