# Changelog Archive (pre-1.39.0)

inline in `SKILL.md`'s `## Changelog`. Moved here in the BL-128 second-round context-cost
extraction — see `.claude/rules/versioning.md`. This file is
purely historical: the operative rules, gotchas, and fixes each entry introduced are already
captured in the current SKILL.md procedure (and in `references/coverage-matrix.md` /
`references/open-items.md` where relevant) — this archive is for provenance and
archaeology ("when/why did X change"), not for executing the skill.
