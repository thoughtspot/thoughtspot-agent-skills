## Verdict

The repo is structurally sound and the framework is working — angle 17 caught real
behavioural bugs again, and the per-PR validator wall is dense. What this sweep exposes is a
different failure mode from the last one: **several gates are green because they cannot see
the thing they guard.** That class accounts for the most consequential findings, and it is
also the class with the cheapest permanent fixes.

- 🔴 **Silent-wrong-answer and fails-open defects (9 high).** Three are behavioural:
  the Databricks SQL translator discards `CAST` target types that the Snowflake twin maps
  correctly (`CAST(ts AS DATE)` emits the raw timestamp — converted Metric Views return
  different numbers, with no advisory); the new derived-metric support skips every metric
  whose referenced inner metric uses an unqualified column, which is the *documented*
  Semantic View style; and every `git diff --cached` / `git ls-files` helper in
  `tools/validate/` drops octal-quoted paths, so a staged secret in a non-ASCII filename
  passes both the pre-commit gate and the CI `--all` backstop with exit 0. Two are
  gate-blindness: the Databricks smoke-test alias runs a file that asserts against a string
  it built itself, while the file that exercises the real emitter is unreachable; and
  `check_tml.validate_table_tml` — the automated guard for the CLAUDE.md "Critical TML
  invariants" — has zero negative-case tests, so inverting any one of ~14 conditions leaves
  the suite green. Two are product-currency reversals with emit consequences (Databricks
  `rely.at_most_one_match` is 18.1-gated, not universal; date-hierarchy levels must be
  defined on the order *field*, not the source column). Plus a documented-invalid key in the
  Snowflake derived-metric section that BL-031 is about to build from, and a viz-binding
  form the shared schema says is dropped on import which every liveboard emitter emits.
- 🟠 **Currency drift, missing codification, and unenforced conventions (47 medium).**
  Worked examples sit outside the currency-anchor net entirely (11 of 17 unanchored), which
  is why the canonical to-Snowflake example still teaches Worksheet TML as the *basic* path
  three majors after Worksheet import was blocked. Angle 11 re-verifies four 2026-07-29
  findings as fully open and adds three more, all with shipped replacements and green
  baselines — i.e. all validator-ready now. Angle 18 finds the audit workflow's own research
  tools unallowlisted (so a 14-agent sweep blocks on interactive prompts), an
  invalid-JSON settings example the file itself tells you to `cp`, and no gate at all tying
  `.claude/agents` frontmatter to the routing table it is required to match.
- 🟡 **Documentation completeness, dependency hygiene, and preventive widening (30 low).**
  Function-census gaps in the Tableau mapping (spatial, `MODEL_*`/`SCRIPT_*`,
  `RANK_PERCENTILE`, `ATAN2`/`DIV`), unbounded dependency ranges, a Python floor that goes
  EOL in ~2 months, two convert-only validator globs worth widening, and five recorded
  no-action items so the next sweep does not re-litigate them.

Nothing here is a security incident. The secrets-gate finding (4.2) is a *latent*
fails-open, not an observed leak — but it is the highest-leverage single fix in the sweep.
