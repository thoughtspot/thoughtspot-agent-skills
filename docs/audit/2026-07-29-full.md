# Repo Audit -- full

**Scope:** full. **Method:** synthesis of raw findings across external angles 13 (product-currency,
per-platform), 14 (performance), 16 (dependency-currency), 18 (harness-currency), and internal
angles 1 (dead files), 4 (tools quality), 5 (ts-cli gaps), 6 (testing value), 7 (PR validation),
11 (codification), 17 (change correctness -- `max` `/code-review` over the 106-commit delta since
2026-07-22). **Rubric:** `.claude/rules/repo-audit.md`. 63 raw findings deduplicated to **58**
(5 high / 23 medium / 30 low, including positive/FYI records).

## Verdict

The gate system continues to hold for the surfaces it covers -- mappings carry current anchors,
the CLI-first rule is clean of raw HTTP across all skills, and CI dependency gates are green.
The story of this cycle is what the gates *don't* cover:

- **HIGH -- The freshly rebuilt `ts migrate` engine shipped four correctness bugs in its
  safety-critical paths (4 high).** `ts migrate rollback` crashes with an ImportError on every
  invocation (function-local import of constants the apply rewrite deleted -- and even fixed, it
  reads the old ledger shape, so it would report "Nothing to roll back" after a real apply).
  Multi-model applies bind ALL content to `targets[0]`. `repoint_source` rebinds every
  `tables[]` entry, corrupting multi-source dependents. The tenant-isolation segmentation gate
  reads cluster-wide variables instead of the target's, producing false passes exactly when the
  RLS refusal matters. All four are in the post-2026-07-22 delta (migrate rebuild, PRs
  #364-#376) and none is caught by a test -- the rollback path has zero coverage. This is the
  angle-17 backstop doing precisely its job.
- **HIGH -- The harness advertises a broken publish flow.** `.claude/agents/repo-publisher.md`
  still documents commit -> `git push origin main` -> stage-sync, which branch protection
  (enforce_admins) rejects outright; `model-routing.md` cites this flow as its canonical
  sonnet-tier example. Stale since branch protection landed.
- **MEDIUM -- Product drift is again completeness, not broken claims.** Snowflake SV
  materializations (public preview 10.24) add a top-level `max_staleness` key our "Complete
  Schema" lacks and a DDL clause the BL-100 parser grammar doesn't anticipate; Databricks
  materialization went GA with new `cluster_by`/`partition_by` fields, wildcards turn out to be
  18.2-gated and legal in `measures:`, and `synonyms:` has a hard 10-per-column/255-char limit
  the to-direction never clamps.
- **MEDIUM -- Codification debt has a new shape: skills importing ts-cli internals.**
  ts-object-model-aggregates has the LLM import the private `_aggregate_name` and the RLS
  force-add helper directly -- the exact gap class ts-cli.md exists to prevent, and invisible
  to check_patterns (which only knows about `requests`).
