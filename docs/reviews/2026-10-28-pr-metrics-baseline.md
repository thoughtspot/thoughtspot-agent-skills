# PR metrics baseline — 2026-07-01 to 2026-10-28

Generated by `tools/pr-metrics/collect.py`; do not edit by hand — rerun it.

- **Window:** PRs created between 2026-07-01 and 2026-10-28 (UTC, inclusive). Rerun with the same arguments to compare.
- **Method:** PR data from `gh pr list`, review lists from the GitHub reviews API per PR. A *review round* is a `CHANGES_REQUESTED` review, or a `COMMENTED` review with a body of at least 200 characters. *Days open* runs from creation to merge or close; still-open PRs are left out of that median. *Changed lines* is additions + deletions. Bots are reported apart from external contributors.
- **Post-merge defects** come from `tools/pr-metrics/attributions.yaml` and are counted against the group of the PR that *introduced* the defect, not the one that fixed it. The attributions file started empty at this baseline and is filled as fixes land, so a zero below means "none attributed yet", not "none exist".
- **Privacy:** keyed by PR number only; no author is named.
