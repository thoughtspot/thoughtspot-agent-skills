# PR metrics baseline — 2026-07-01 to 2026-10-28

Generated by `tools/pr-metrics/collect.py`; do not edit by hand — rerun it.

- **Window:** PRs created between 2026-07-01 and 2026-10-28 (UTC, inclusive), collected at 2026-10-28 05:17 UTC. PRs still open at collection can gain reviews and lines or close later, so the same arguments run later give different numbers: compare against this snapshot, not a rerun.
- **Method:** PR data from `gh pr list`, review lists from the GitHub reviews API per PR. A *review round* is a `CHANGES_REQUESTED` review, or a `COMMENTED` review with a body of at least 200 characters, by someone other than the PR's author and not a bot. *Days open* runs from creation to merge or close; still-open PRs are left out of that median only, and are included in the PR counts, changed lines and review rounds. *Changed lines* is additions + deletions. Bots are reported apart from external contributors.
- **Reviews posted as conversation comments** are invisible to the reviews API and are counted only through the hand-kept `tools/pr-metrics/rounds_overrides.yaml`, whose count replaces the computed one for the PRs it lists. Overridden here: #242, #252, #254, #356, #440, #506.
- **Post-merge defects** come from `tools/pr-metrics/attributions.yaml` and are counted against the group of the PR that *introduced* the defect, not the one that fixed it. The attributions file started empty at this baseline and is filled as fixes land, so a zero below means "none attributed yet", not "none exist".
- **Not measured:** the spec's *blocker findings per first-round review* (§5 C7). It needs each first-round review classified by hand; this tool does not compute it.
- **Privacy:** keyed by PR number only; no author or reviewer is named.
